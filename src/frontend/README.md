# Fraud Detection Dashboard (MVP)

A very simple React dashboard that talks to your FastAPI backend.

## Prerequisites

- Node.js 18+ installed
- Your backend running at `http://127.0.0.1:8000`
  - Start it from the project root:
    ```bash
    cd src
    uvicorn backend.main:app --reload
    ```

## Quick start

```bash
cd src/frontend
npm install
npm run dev
